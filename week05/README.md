## Потоковый режим

Кадры энкодера (40 мс) делятся на чанки по `chunk` кадров. Кадр видит все кадры до конца своего чанка и не больше `left` кадров до его начала. Посчитать такую модель можно двумя способами, и результаты должны совпадать:

- **маскированный forward** `model.encode(wav, len, chunk, left)` — вся запись сразу с маской; так учим и считаем WER;
- **кэш-движок** `Streamer` — звук подаётся кусками, слои хранят кэш прошлого; так модель работает на самом деле.

**Задержка слова** = сколько звука было подано, когда движок выдал кадр с последней буквой слова, минус конец слова по разметке. `check.py` подаёт звук кусками по 10 мс.
